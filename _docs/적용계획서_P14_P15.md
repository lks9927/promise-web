## 3. 위험과 대비
- **P14**: `new_only`라 기존 팀장 영향 없음. 광수가 `all`로 바꾸는 순간 서류 없는 팀장 7명은 배정 제외됨 → 안내문 발송 후 서류가 모인 뒤에만 `all`.
- **P15 잠금 시점(광수 결정 반영)**: 장례 종료(team_settling) 후에도 등록·취소 가능, 본사 입금 확인(hq_check) 이후 잠김. 이미 `pending`/`paid`/`completed` 정산이 있으면 거부. 상태 허용표: `_docs/추가매출_상태허용표.md`.
- **확인 필요(보완 보고에서 올라온 질문)**: 팀장이 '송금했음' 알리는 상태값은 시스템에 없음(관리자가 입금확인 누르는 방식). 추후 도입 여부는 별도 결정.
- **알림 중복 문제(보류 항목)**: 팀장 수수료 금액을 0 초과로 입력하기 전에 먼저 수정 필요. 이번 적용은 금액 변화 없음.
- 세무: 추가 매출 수수료 50%(부가세 포함)의 세무 처리는 `_docs/추가매출_세무확인사항.md` 확인 대기.
- 백업: Supabase 무료 플랜은 자동 백업이 없어 단계 A의 JSON이 유일한 복구 자료.
