작성 2026-11-10. 상태: 계획만 작성, 운영 미적용. 검토 후 광수 직접 확인 뒤에만 진행.

## 0. 무엇이 바뀌나

## 1. 이번에 찾은 문제와 수정 (시험으로 확인)
- **P16 원안 누락**: `profiles` 는 열 단위 권한이라 새 열에 UPDATE 권한을 따로 줘야 함(원안은 주지 않아 PATCH 가 permission denied). 수정함.
- **푸시 읽기 경로**: 관리자 화면이 다른 사용자의 `push_subscription` 을 직접 읽던 코드(`pushNotification.js`)는 P12 후 막힘. → 서버 `api/send-push.js` 가 `userIds` 로 서비스 롤로 조회하도록 변경(관리자 인증 유지, 구독 정보가 브라우저로 내려오지 않음).
- **P12 0명 버그 재발 방지**: `_sql_admin_dealer/_시험/profile_select_audit.mjs` 가 코드의 profiles select/필터/embed 69곳을 검사해 공개 12열 밖의 열 사용을 잡음(위 push 2건을 정확히 잡았고 수정 후 0건). 예행연습에 4개 역할(관리자·딜러·팀장·고객)로 공개 열 읽기 성공과 `SELECT *`·email·fcm_token 거부를 정확히 비교하는 시험 추가.
- **P19 시험**: 일부러 옛 방식(UPDATE)으로 되돌려 시험이 실패(`extra_updates=1`)하는 것을 확인(헛통과 아님).
- 참고(기존 문제): `PackagePanel.jsx:22` 의 embed 가 profiles 에 없는 `grade` 를 요청함. 이번 범위 밖, 별도 점검.

## 2. 적용 순서 (SQL 한 파일씩, 단계마다 읽기 전용 확인, 실패 시 즉시 중단·보고)
| 단계 | 내용 | 확인(읽기 전용) | 되돌리기 |
|---|---|---|---|
| A. 백업 | 읽기 전용으로 `profiles` 열 권한 목록·정책·트리거·`commission_policies`·`system_config` 를 JSON으로 노트 폴더 저장, 행 수 대조 | 파일 경로·행 수(partners 17, profiles 수) | - |
| B. P12 | `P12_프로필_민감열_제한.sql` | 공개 12열만 SELECT 권한, RPC 2개 존재, 서비스 롤 열 권한 유지, ego 로 관리자 화면 파트너 17(딜러 10·팀장 7)·고객 목록·메시지 수신자 표시 | 파일 머리말: `GRANT SELECT ON public.profiles TO authenticated;` |
| C. P16 | `P16_웹푸시_구독열.sql` | 열 존재, authenticated UPDATE 권한 있고 SELECT 권한 없음 | 파일 머리말 |
| D. P19 | `P19_알림중복수정.sql` | 트리거 `trg_private_case_usage_fee`(BEFORE INSERT)·함수 2개, 정산·사건 0건 유지, `team_leader_fee` 0 유지, 알림 트리거 켜짐 | 파일 머리말 |
| E. 웹 점검 | build, ssr_smoke, rest_smoke, profile_select_audit | 모두 통과 | 배포 보류 |
| F. 웹 배포 | `vercel deploy --prod` (이번 변경: send-push, pushNotification) | 사이트 200, 배포 후 rest_smoke·ssr_smoke, ego 로 파트너 17 표시, 직전 배포로 롤백 가능 | `vercel rollback` |

- B~D 와 F 사이의 공백은 무해: 푸시 구독 저장이 아직 없고, 새 정산·사건이 없음. P12 후 구배포의 푸시 읽기는 어차피 구독 열이 없어 동작하지 않던 기능.
- 이번에도 금지: 서류 필수 `all` 전환, 안내 문자 발송, `partners.bank_account` 삭제, 팀장 수수료 금액 입력(0 유지).

## 3. 남은 위험
- P12 는 읽기 권한을 줄이는 변경이라 화면 한 곳이라도 제한 열을 읽으면 그 화면이 비게 됨. 정적 점검 + 4역할 예행연습 + 적용 직후 ego 확인으로 대비. 이상 시 B 의 되돌리기 한 줄로 즉시 복구.
- 웹 푸시는 이번에 "구독 저장 + 서버 발송 경로"까지만 정리. 아이폰 푸시 이슈(PWA 홈 화면 추가 필요)는 별도.
- 호출 알림은 계속 문자(SMS)가 기본.
