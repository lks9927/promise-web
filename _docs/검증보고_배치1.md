|---|---|---|---|
| 고객 화면 팀장 프로필 계층 참조 | 확인됨 | `team_leader:team_leader_id ( name, ... )` | `CustomerStatus.jsx`에서 직접 필드 참조로 수정 |
| P14 전 `business_doc_path` 일괄 SELECT | 확인됨 | `select('current_status, is_working, business_doc_path')` | 상태 조회와 서류 조회를 분리하고 실패 시 서류 미완료 폴백 |
| P18 `started_at` 부재 및 V2 폴백 불완전 | 오탐 | `ADD COLUMN IF NOT EXISTS started_at timestamptz` | P3a가 선행 열을 만들고 적용 시험도 해당 열을 확인한다. SQL/화면 미수정 |
| 팀장 승인 오류 사유 은닉 | 확인됨 | `showToast(... '상태 변경 중 오류...')` | `translateError(error)`로 실제 번역 오류 안내 |

| `extra_sales_fee` 배지의 출금 색상 | 확인됨 | `item.type.includes('remittance')` | `isInboundFee(item.type)`로 입금 배지 처리 |

## 2. 낮음 항목 표본 3건

| 항목 | 분류 | 근거 | 조치 |
|---|---|---|---|
| 사진 업로드 실패 후 항목 저장 | 확인됨 | `if (uploadErr) ... return null` | 업로드 오류를 throw하여 항목 등록 및 성공 토스트를 중단 |
| `extra_sales_fee_rate` 기본값 0/DB 50 불일치 | 확인됨 | 화면 `extra_sales_fee_rate: 0`, SQL `DEFAULT 50` | 수정 보류: 사용자 지시의 금액·비율 하드코딩 금지에 따라 50을 화면 상수로 덮어쓰지 않음 |
| update/upsert 오류 무시 | 확인됨 | `await ...upsert({ key, value: newValue })` | SettingsPanel, Profile은 오류 안내/되돌림, Login은 기기 메타데이터 로컬 반영을 중단 |

## 4. Gemini G1/G2 실행과 SQL 시험

요청된 `agy --print ... --model gemini-3.8-flash-high ...`를 G1/G2 각각 실행했다. CLI가 로컬 Antigravity/Gemini OAuth 로그인을 요구해 결과 파일을 만들지 못했다. 출력의 핵심 사유는 `Authentication required`와 `You are not logged into Antigravity`였다.

따라서 G1 결과의 시나리오별 재검증이라는 전제 조건이 성립하지 않아 `20_tests.sql`에 신규 시험을 추가하지 않았다. 추측성 시험을 넣지 않았으며, 현재 P15 블록은 취소/복구, 0 합계, 상태 잠금, 37/41% 정확 계산을 이미 포함한다.
