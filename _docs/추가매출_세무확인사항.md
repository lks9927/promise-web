# 추가 매출 수수료 정산 관련 세무 확인 필요 사항

## 1. 개요 및 배경
- **기능 목적**: 장례 진행 중 상주의 요청으로 발생하는 추가 품목 및 서비스(영정사진, 제단꽃, 수의 변경 등)에 대해 팀장이 항목을 등록하고, 장례 종료 시 본사와 팀장 간 정산 수수료를 확정·정산합니다.
- **수수료 정책**: 추가 매출 총액에 대해 정책 수수료율(`extra_sales_fee_rate`, 기본 50%)을 적용하여 본사 수수료(`extra_sales_fee`)를 산출하고, 팀장이 본사 기본 사용료(`usage_fee_remittance`)와 함께 일괄 입금합니다.

## 2. 세무사 검토 및 확인 필요 항목

### ① 수수료의 부가세(VAT 10%) 포함 산정 기준
- 현재 시스템 정책: 본사 수수료는 **부가세 포함 금액(Gross Amount)**으로 산정됩니다.
  - 수수료 총액(팀장 납부액) = `ROUND(추가 매출 합계 × 수수료율 / 100)` (원 단위 정수)
  - 공급가액(본사 매출 공급가) = `ROUND(수수료 총액 / 1.1)` (원 단위 정수)
  - 부가가치세 = `수수료 총액 - 공급가액`
- **확인 사항**:
  - 본사가 팀장에게 발급할 세금계산서의 공급가액과 부가세 분리 시, 위 반올림(ROUND) 방식이 세법상 세금계산서 발행 표준 단수 처리 기준에 적합한지 검토가 필요합니다.
  - 시스템은 단일 SQL 함수(`public.extra_sales_fee_split`)에서 분리 계산식을 관리하므로 세무사 자문에 따라 향후 계산식 조정이 용이하도록 설계되었습니다.

### ② 팀장(면세사업자)의 매입세액 공제 불가 사항
- **현황**: 장례지도사(팀장)는 통상 인적용역 제공자 또는 간이/면세사업자로 등록되어 있습니다.
- **영향**:
  - 팀장은 본사로부터 세금계산서(매입세금계산서)를 수취하더라도 면세사업자 특성상 부가가치세 매입세액 공제를 받을 수 없습니다.
  - 따라서 팀장의 실제 경제적 부담은 부가세 포함 수수료 전액(포함가 100%)이 되며, 팀장의 순수익은 `추가 매출 합계 - 본사 수수료(부가세 포함가)`가 됩니다.
- **확인 사항**:
  - 팀장에게 세금계산서 발행 시 사업자 등록 형태(면세사업자, 간이과세자, 프리랜서 원천징수 대상 등)에 따른 적격 증빙 발급 유형을 최종 점검할 필요가 있습니다.

### ③ 상주(최종 소비자) 대상 매출 증빙 및 현금영수증 발행 주체
- **현황**: 상주가 결제한 추가 매출 대금은 현장에서 팀장이 수령하거나 상주가 직접 결제합니다.
- **확인 사항**:
  - 상주 대상 현금영수증 또는 영수증 발급 주체가 본사인지, 아니면 독립 용역을 수행하는 팀장인지에 대한 거래 계약 구조 점검이 필요합니다.
