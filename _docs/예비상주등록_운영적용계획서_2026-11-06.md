## 1. 무엇이 바뀌나
| 구분 | 내용 |
|---|---|
| 딜러 | 승인된 딜러마다 금액 없는 **명함용 쿠폰 1개**가 자동 발급됨(승인 시 자동, 지금 승인된 딜러 10명은 일괄). 딜러 홈에 큰 **'내 명함 QR'** 버튼(PNG·SVG 저장)과 **'내 안심 혜택 명단'**(마스킹 이름·관계·보관중/접수완료). 팀장은 대상 아님·열람 불가 |

| 접수 연결 | 명함 쿠폰으로 실제 접수되면 같은 전화번호의 예비 등록이 **접수완료**로 바뀌고, 딜러에게 귀속(수수료)됨. 명함 쿠폰은 계속 재사용 |
| 관리자 | 설정에 '가족 안심 혜택'(이름·한 줄 설명·금액 선택) 입력 칸. 금액·문구는 코드에 박지 않음 |

## 2. 바뀌는 기존 함수 (주의)
- `get_coupon_public`: 기존 4개 값은 그대로, `is_card`·`dealer_name`만 추가.
- `auto_update_coupon_status`: 명함 쿠폰은 '사용됨'으로 바꾸지 않음(그 외 동일).
- `submit_emergency_case`: 명함 쿠폰 접수 시 예비 등록을 접수완료로 전환(그 외 동일).
- `calculate_settlements`: **명함 쿠폰 사건에는 고객 캐시백 정산을 만들지 않음**(혜택이 정해지기 전에 정책 금액(예: 5만 원)이 자동 지급되는 것을 막기 위해). 딜러 수수료·마스터 관리수수료는 그대로. 일반 쿠폰은 기존대로 캐시백 생성.

## 3. 가족용 익명 등록 함수의 방어 장치 (승인 요청 대상)
- 예비 등록·시도 기록 표는 **누구도 직접 읽거나 쓸 수 없음**(RLS+권한 회수). 함수로만 접근.
- 등록 함수는 **동의 체크 필수**, 유효한 명함 쿠폰만, 전화번호 형식(01로 시작 10~11자리)·이름 길이·관계 목록 검증.
- **같은 번호 1시간 3회 제한**, 같은 쿠폰+번호 재등록은 새로 만들지 않고 기존 기록 반환(중복·도배 방지).
- 응답에는 딜러 이름·혜택 이름 외 개인정보를 넣지 않음. 딜러 알림에는 **마스킹 이름**과 관계만(전화번호 없음).
- 딜러가 보는 명단 함수는 마스킹 이름·관계·상태·등록일만 반환(전화번호·원본 이름은 컬럼 자체가 없음). 다른 딜러·팀장은 빈 결과.
- 남는 위험: 로그인 없는 입력이라 **다른 번호 여러 개를 연속 입력하는 도배**는 막지 못함(번호별 제한). 심해지면 쿠폰별 시간당 총량 제한이나 캡차를 추가해야 함.

## 4. 적용 순서 (사장님 승인 후)
1. 적용 직전 읽기 전용 백업(바뀌는 함수 4개 본문: `백업_적용전_함수정의_2026-11-04.sql`에 있음 + P4/P1a 이후 본문은 해당 SQL 파일).
2. Supabase SQL 편집기(ego-browser)에서 `P10_예비상주.sql` 한 번 실행(단일 문장 실행이라 실패 시 전체 자동 취소).
3. 읽기 전용 점검: `select count(*) from coupons where is_card;` → 승인 딜러 10명 = 10 / `select proname from pg_proc where proname in ('submit_pre_registration','get_my_pre_registrations','get_my_card_coupon','get_family_benefit_public');` → 4개 / `pre_registrations` RLS 켜짐 / 알림 트리거 2개 켜짐 / `partners` 를 참조하는 FK 0개 / `bash _sql_admin_dealer/_시험/rest_smoke.sh`.
4. REST 점검(공개 키): `get_family_benefit_public` 호출이 200이고 name null, 잘못된 코드로 `submit_pre_registration` 호출 시 한국어 오류(500 아님). 실제 가족 데이터는 만들지 않음.
5. 웹 배포(`vercel --prod` 후 롤백 이력이 있으면 `vercel promote` 확인), 배포 전 `npm run build`·`ssr_smoke.sh` 통과 확인.
6. 배포 후 읽기 전용 확인: 딜러 계정 '내 명함 QR', 관리자 설정 '가족 안심 혜택'.
